Movie App
Αυτή είναι μια μοντέρνα και διαδραστική εφαρμογή web για την αναζήτηση και εξερεύνηση ταινιών, η οποία κατασκευάστηκε με τη χρήση JavaScript.
Η εφαρμογή προσφέρει δυνατότητες αναζήτησης ταινιών σε πραγματικό χρόνο και προβολής βασικών πληροφοριών όπως τίτλος, αφίσα, βαθμολογία και περιγραφή, μέσα από ένα καθαρό και responsive περιβάλλον εργασίας.
Για την ανάπτυξή της χρησιμοποιήθηκαν HTML και CSS για τη δομή και το σχεδιασμό, καθώς και JavaScript για τη λογική και τη διαχείριση των δεδομένων.
Για να την τρέξετε τοπικά, μπορείτε να κάνετε clone το repository, να ανοίξετε τον φάκελο του project και στη συνέχεια να ανοίξετε το αρχείο index.html στον browser της επιλογής σας.
